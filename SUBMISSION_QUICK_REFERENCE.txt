## Troubleshooting Before Submission

**Problem: App says "Render is starting"**
- Wait 3-5 minutes for Render to boot up
- Check dashboard logs
- May need to trigger rebuild

**Problem: "Application error"**
- Check Render dashboard logs
- Verify DATABASE_URL is set
- Check Cloudinary credentials
- Look for missing environment variables

**Problem: Images not showing**
- Verify Cloudinary is active
- Check API credentials
- Test image upload on test album

**Problem: Can't login with admin/admin123**
- Run: python manage.py createsuperuser
- Create new admin account locally
- Upload changes to production
