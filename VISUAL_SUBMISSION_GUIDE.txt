## COMMON MISTAKES (AVOID THESE!)

```
❌ MISTAKE #1: Forgetting to check if app is live
   └─ SOLUTION: Test https://cloud-render-demo.onrender.com NOW

❌ MISTAKE #2: Repository is set to private
   └─ SOLUTION: Go to GitHub settings, make it PUBLIC

❌ MISTAKE #3: Submitting without all 3 items
   └─ SOLUTION: Make sure document has URL + Repository + Docs

❌ MISTAKE #4: Pausing the Render service before grading
   └─ SOLUTION: Keep service ACTIVE - don't pause or delete

❌ MISTAKE #5: Waiting until last minute to submit
   └─ SOLUTION: Submit 2-3 days before deadline

❌ MISTAKE #6: Document has wrong URLs
   └─ SOLUTION: Copy-paste URLs, don't type manually

❌ MISTAKE #7: Missing setup instructions
   └─ SOLUTION: Include full setup guide from README.md

❌ MISTAKE #8: Credentials are wrong or missing
   └─ SOLUTION: Include: admin / admin123 in document

❌ MISTAKE #9: Submitting in wrong file format
   └─ SOLUTION: Use PDF or DOCX, not TXT

❌ MISTAKE #10: Not verifying after upload
   └─ SOLUTION: Download submission back and verify it's there
```
