PROJECT TITLE
Photo Album Management System

PROJECT DESCRIPTION
A production-ready Django web application for managing photo albums with secure user authentication, cloud-based image storage using Cloudinary, role-based access control, and a modern responsive user interface. The application is fully deployed on Render.com with PostgreSQL database and supports multiple users creating and managing photo collections.

D. Setup Instructions for Local Development

   Step 1: Clone Repository
   git clone https://github.com/diangchristian/IT383-Assignment6.git
   cd IT383-Assignment6

   Step 2: Create Virtual Environment
   python -m venv venv
   
   # On Windows:
   venv\Scripts\activate
   
   # On Mac/Linux:
   source venv/bin/activate

   Step 3: Install Dependencies
   pip install -r requirements.txt

   Step 4: Create .env File
   Create a file named ".env" in project root with:
   
   DEBUG=True
   SECRET_KEY=your-random-secret-key-here
   CLOUDINARY_CLOUD_NAME=your-cloudinary-name
   CLOUDINARY_API_KEY=your-api-key
   CLOUDINARY_API_SECRET=your-api-secret

   Step 5: Run Database Migrations
   python manage.py migrate

   Step 6: Create Admin User (Optional)
   python manage.py createsuperuser

   Step 7: Start Development Server
   python manage.py runserver

   Step 8: Access Application
   Open: http://127.0.0.1:8000/

E. Deployment Information

   Platform: Render.com
   
   Deployment Steps:
   1. Connect GitHub repository to Render
   2. Set environment variables on Render dashboard
   3. Configure build and start commands
   4. Create PostgreSQL database on Render
   5. Deploy application
   
   Build Command:
   pip install -r requirements.txt && python manage.py migrate && python manage.py collectstatic --noinput
   
   Start Command:
   gunicorn recipe_project.wsgi:application
   
   Environment Variables Required:
   - SECRET_KEY (strong random string)
   - DEBUG=False
   - DATABASE_URL (PostgreSQL connection string)
   - CLOUDINARY_CLOUD_NAME
   - CLOUDINARY_API_KEY
   - CLOUDINARY_API_SECRET
   - ALLOWED_HOSTS (your Render domain)

SECTION 11: TROUBLESHOOTING

Issue: Application takes a long time to load
Solution: Render free tier may have cold starts. Wait 3-5 minutes after deployment.

Issue: Application shows error 500
Solution: Check Render dashboard logs. May be missing environment variable.

Issue: Images don't display
Solution: Verify Cloudinary credentials. Check API key and secret are correct.

Issue: Can't login with credentials
Solution: Run migrations. May need to create new superuser account.

Issue: Database connection error
Solution: Verify DATABASE_URL in Render environment. Check PostgreSQL is active.

Issue: Static files (CSS) not loading
Solution: Verify WhiteNoise is configured. Run: python manage.py collectstatic

For more help, see README.md in repository.
