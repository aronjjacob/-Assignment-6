SETUP INSTRUCTIONS FOR LOCAL DEVELOPMENT

1. Clone the Repository
   git clone https://github.com/diangchristian/IT383-Assignment6.git
   cd IT383-Assignment6

2. Create Virtual Environment
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Mac/Linux:
   source venv/bin/activate

3. Install Dependencies
   pip install -r requirements.txt

4. Create .env File
   Create a file named .env with:
   DEBUG=True
   SECRET_KEY=your-secret-key-here
   CLOUDINARY_CLOUD_NAME=your-cloudinary-name
   CLOUDINARY_API_KEY=your-api-key
   CLOUDINARY_API_SECRET=your-api-secret

5. Run Database Migrations
   python manage.py migrate

6. Create Superuser (Optional)
   python manage.py createsuperuser

7. Start Development Server
   python manage.py runserver

8. Access Application
   Open browser to: http://127.0.0.1:8000/


DEPLOYMENT ON RENDER.COM

This application is deployed on Render.com. The deployment includes:

1. GitHub Integration
   - Repository is connected to Render
   - Automatic deployments on push to main branch
   - Build process includes migrations and static file collection

2. Environment Variables Set on Render
   - DEBUG=False (production)
   - SECRET_KEY (strong random key)
   - DATABASE_URL (PostgreSQL connection)
   - CLOUDINARY credentials
   - ALLOWED_HOSTS (render domain)

3. Build and Deployment
   - Build command: pip install -r requirements.txt && python manage.py migrate

4. Database
   - PostgreSQL hosted on Render

   - Migrations run on deploy

5. Static Files

TROUBLESHOOTING

Issue: Application shows "Render is starting" or loading slowly
Solution: Wait 3-5 minutes for Render to initialize. Cold starts can take time.

Issue: "Application error" or 500 error
Solution: Check Render dashboard logs. May be missing environment variables.

Issue: Images not displaying
Solution: Verify Cloudinary credentials in Render environment variables.

Issue: Can't login with admin/admin123
Solution: Run migrations. May need to create new superuser.

Issue: Database connection error
Solution: Verify DATABASE_URL environment variable is set correctly on Render.

Issue: Static files not loading
Solution: Verify WhiteNoise is configured. Run: python manage.py collectstatic

More help: See README.md in repository for full troubleshooting guide.
